# Dynamic_TDTSP-Metaheuristic-Optimization-for-Unpredictable-Networks
Optimization project solving a Dynamic TSP with road blockages and time-varying costs. Features mathematical modeling, NP-completeness proof, and metaheuristic resolution using Genetic Algorithms (GA) and Ant Colony Optimization (ACO). Includes hyperparameter tuning (OFAT) and lower bound analysis with Python/PuLP
